## Other folders

| Path | Contents |
|---|---|
| `plan/PLAN.md` | Phases P0 to P7 with tasks, sizes, docs to read and acceptance criteria |
| `plan/PREREQUISITES.md` | Software to install, accounts and keys, approved npm packages |
| `schemas/` | JSON Schemas sent to the model (strict structured-output subset); generated by `tools/build_schemas.py` |
| `prompts/` | System prompts (frame turn, decision turn, router, repair, meta) and Jev questions; imported by the Worker |
| `fixtures/rent-or-buy/` | Golden conversation (3 decision turns, a clarify, a meta, a grade) and expected log and states |
| `fixtures/rent-or-buy-edits/` | Second golden fixture (10 versions): frame edit, rewinds, split proposals, dismiss, accept, a failed turn, "just a comment" |
| `fixtures/canonical-vectors.json` | 20 canonical-JSON and SHA-256 test vectors (Python and JavaScript agree) |
| `fixtures/router-cases.json` | 32 labelled messages for the turn check |
| `evals/scenarios.md` | 12 end-to-end scenarios and the metrics to report |
| `tools/reference_engine.py` | Executable spec of the engine; generates and checks the expected fixtures; `--selftest` holds the error cases |
| `tools/check_hashes.mjs` | Recomputes the vectors and every fixture log hash in Node: a 10-line reference for the TS canonicaliser |
| `tools/build_schemas.py` | Generates `schemas/` from one set of definitions |
| `design/` | Theme tokens, prototype sources, legacy CLEAR exports (see `design/README.md`) |

## Checking the kit

Python 3.10+ with no packages, and Node:

```sh
pnpm check:kit
```

It runs the reference engine's selftest, checks both fixture folders against their expected files, and recomputes the hash vectors in Node.
