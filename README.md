# Settle · implementation kit

Everything needed to build Settle locally with a coding agent: specs, a phased task plan, model-facing JSON schemas, prompts, golden test fixtures generated by an executable reference engine, theme tokens for shadcn/ui, and the approved prototype.

It contains no application code and no base project. You create the base locally (step 2), and the agent builds the app phase by phase from `plan/PLAN.md`.

## What Settle is

A local-first decision helper. You talk through one decision on the left; a live decision panel on the right updates after every message that moves the decision: direction, confidence and risk, a weighted option matrix, gates, an action ceiling, next actions, predictions you grade later, and an audit trail. Messages that don't move the decision are not applied, and you're asked to say more. The model proposes; a deterministic engine computes every number. Stack: React, Vite, shadcn/ui, Dexie, Zod, OpenRouter for reasoning, Jev for the turn check.

## Getting started

1. Install the prerequisites and create the accounts in `plan/PREREQUISITES.md`.
2. Create the base project (your PWA starter, or `pnpm create vite settle --template react-ts`) and `git init`.
3. Copy everything in this kit into the repo root and commit.
4. Check the kit (Python 3.10+ with no packages; Node for the last line):
   ```
   python3 tools/reference_engine.py --selftest
   python3 tools/reference_engine.py --check fixtures/rent-or-buy/conversation.json fixtures/rent-or-buy/expected
   python3 tools/reference_engine.py --check fixtures/rent-or-buy-edits/conversation.json fixtures/rent-or-buy-edits/expected
   node tools/check_hashes.mjs fixtures/canonical-vectors.json
   ```
5. Start your agent in the repo (for example `claude` for Claude Code) and give it:
   > Read CLAUDE.md, then plan/PLAN.md. Start with task P0.1. Before each task, restate its acceptance criteria and the files you'll touch; stop after each task for my review.
6. Review after each task; run the three spikes (S1 to S3) alongside phase 1.
